# Workspace Layout

- `data/raw/`: original input datasets (e.g. UMI zarr)
- `data/processed/`: derived intermediate data
- `notebooks/`: analysis and conversion notebooks
- `scripts/`: reusable Python scripts/CLI tools
- `assets/urdf/`: robot model files (URDF/XML)
- `outputs/videos/`: rendered videos
- `outputs/images/`: rendered images/frames
- `outputs/datasets/`: generated datasets (LeRobot, test datasets)
- `outputs/tmp/`: cache and temporary artifacts
